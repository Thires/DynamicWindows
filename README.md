# DynamicWindows
creates windows for DragonRealms when using genie frontend<br>
can handle:<br>
aim timer<br>
bank debt<br>
bank deposit<br>
bank transfer<br>
bank withdraw<br>
bug window<br>
injury window for others<br>
injury window for self<br>
magical feats forgetting<br>
magical feats learning<br>
profile /edit<br>
shopping window<br>
spells choosing<br>
store window<br>
tdp plan<br>
